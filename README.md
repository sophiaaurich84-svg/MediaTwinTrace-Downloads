# MediaTwinTrace

MediaTwinTrace findet doppelte und ähnliche Fotos und Videos auf ausgewählten Laufwerken und in Ordnern. Die Medienanalyse läuft lokal auf deinem PC.

## Download

[Windows-Downloads und Versionshinweise](https://github.com/sophiaaurich84-svg/MediaTwinTrace-Downloads/releases)

Das klassische Setup ist für Windows 10 und 11 auf PCs mit Intel- oder AMD-Prozessor und x64 vorgesehen. MediaTwinTrace ist 24 Stunden kostenlos testbar. Die Vollversion kostet einmalig 9,99 €.

Support findest du in der App unter **Service**.
